# New Data

This page covers extending the database with new tables and query methods.

## 1. Add a table

In `DatabaseService.InitializeAsync()`, add a `CREATE TABLE IF NOT EXISTS` statement:

```csharp
await using var cmd = _connection.CreateCommand();
cmd.CommandText = """
    CREATE TABLE IF NOT EXISTS MyData (
        Id INTEGER PRIMARY KEY AUTOINCREMENT,
        GuildId TEXT NOT NULL,
        Key TEXT NOT NULL,
        Value TEXT,
        CreatedAt TEXT NOT NULL
    )
    """;
await cmd.ExecuteNonQueryAsync();
```

## 2. Add query methods

Add methods to `DatabaseService`:

```csharp
public async Task InsertMyDataAsync(ulong guildId, string key, string value)
{
    await using var cmd = _connection.CreateCommand();
    cmd.CommandText = """
        INSERT INTO MyData (GuildId, Key, Value, CreatedAt)
        VALUES (@guildId, @key, @value, @createdAt)
        """;
    cmd.Parameters.AddWithValue("@guildId", guildId.ToString(CultureInfo.InvariantCulture));
    cmd.Parameters.AddWithValue("@key", key);
    cmd.Parameters.AddWithValue("@value", value);
    cmd.Parameters.AddWithValue("@createdAt", DateTime.UtcNow.ToString("O", CultureInfo.InvariantCulture));
    await cmd.ExecuteNonQueryAsync();
}

public async Task<string?> GetMyDataAsync(ulong guildId, string key)
{
    await using var cmd = _connection.CreateCommand();
    cmd.CommandText = """
        SELECT Value FROM MyData
        WHERE GuildId = @guildId AND Key = @key
        LIMIT 1
        """;
    cmd.Parameters.AddWithValue("@guildId", guildId.ToString(CultureInfo.InvariantCulture));
    cmd.Parameters.AddWithValue("@key", key);
    var result = await cmd.ExecuteScalarAsync();
    return result as string;
}
```

## Database conventions

### ID storage

Guild and user IDs are stored as `TEXT` (not `INTEGER`):

```csharp
cmd.Parameters.AddWithValue("@guildId", guildId.ToString(CultureInfo.InvariantCulture));
```

SQLite's `INTEGER` type is 64-bit. Discord snowflakes can be up to 64-bit unsigned, which exceeds `long.MaxValue` in some operations. Storing as `TEXT` avoids overflow.

### Date/time storage

All timestamps are ISO 8601 strings:

```csharp
DateTime.UtcNow.ToString("O", CultureInfo.InvariantCulture)
// Example: "2026-07-04T12:34:56.7890123Z"
```

The `"O"` format specifier produces round-trippable output. ISO 8601 strings are human-readable and sort correctly lexicographically when using UTC.

### Parameterized queries

Always use `@parameters` to prevent SQL injection:

```csharp
cmd.Parameters.AddWithValue("@value", value);
```

Never concatenate user input into SQL strings.

### CultureInfo.InvariantCulture

All `ToString()` conversions for database values must use `CultureInfo.InvariantCulture` to ensure consistent formatting regardless of the system locale.

### Single connection

The `SqliteConnection` is opened once and kept open. Do not create or dispose connections in individual methods.

## Adding a new index

For performance on large tables, add indexes:

```csharp
cmd.CommandText = """
    CREATE INDEX IF NOT EXISTS IX_MyData_GuildId
    ON MyData (GuildId)
    """;
await cmd.ExecuteNonQueryAsync();
```
